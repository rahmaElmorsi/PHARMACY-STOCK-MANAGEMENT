 Pharmacy Inventory Management System

A clean, responsive web-based CRUD application designed to manage a pharmacy's inventory efficiently. Built using vanilla JavaScript, HTML, and CSS.

 🔗 Live Demo
Check out the live version of the project here: [Pharmacy Stock Management Live](https://rahmaelmorsi.github.io/PHARMACY-STOCK-MANAGEMENT/)

 Features
Create: Add new medicines with title, price, taxes, dose, discount, and category.
Read: Display all stored items dynamically in a clean table format.
Update: Edit existing medicine details easily.
Delete: Remove individual items or clear the entire inventory (`Delete All`).
Search: Filter products instantly by "Title" or "Category".
Local Storage: All data is saved locally in the browser so it persists across sessions.

 Technologies Used
- HTML5
- CSS3
- JavaScript (ES6+)
- Browser LocalStorage
